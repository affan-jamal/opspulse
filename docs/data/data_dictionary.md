# Data dictionary

Generated by `opspulse-etl dictionary` from `src/opspulse/etl/schema.py`, `validate.py` and `config.py`. Do not edit by hand; change the code and regenerate.

Source: Olist Brazilian E-Commerce Public Dataset (Kaggle, CC BY-NC-SA 4.0).
Timestamps are naive local times (America/Sao_Paulo). Money is BRL.

## Business rules

- **Analysis window:** 2017-01-01 to 2018-08-31. The months outside it hold a few hundred orders between them, so trends and recency use this window.
- **Sales** exclude orders with status `canceled`, `unavailable`.
- **Payment reconciliation:** |payment_total − order_total| ≤ R$0.01 is MATCHED, ≤ R$1.00 is MINOR_DIFFERENCE, otherwise SIGNIFICANT_DIFFERENCE. Orders without items or payments get their own status. Differences are not assumed to be fraud: installment interest and vouchers cause many.
- **Geolocation:** points outside latitude (-34.0, 5.5) / longitude (-74.5, -28.5) are excluded from zip centroids. A centroid is an area, never an address.
- **Run failure:** any CRITICAL issue, or any table losing more than 1% of its rows to rejection.
- **Severity:** CRITICAL fails the run · ERROR rejects the row · WARNING keeps the row and records the issue.
